# Advent of Code
This is all of my work for the Advent of Code puzzles! I started in 2024 but foolishly didn't save my work, so I'll be adding my work here as I go.

## Structure
I have each year's puzzles in a respective directory, with subdirectories representing the day (and further subdivision by parts).

The input file(s) (if given) are stored as `.input`, and my solution(s) are stored as `solution.*`. Answers are stored in the comment so you can check your work, since the input files we're given are randomized.

## Goals
1. Complete the challenges: I will prioritize completing the challenges first
2. Clean code: I will attempt to write clean, readable code, following best practices so long as it doesn't sabotage performance. (see next point)
3. Optimization: I may or may not go back and optimize certain challenges if I deem my work too slow, or want a challenge. I will not hyper-optimize if it substantially damages code readability or understanding.
4. Comments: I may leave comments to aid understanding or show my thought process. It may even teach others, let me know if you found something helpful or if you thought my walls of text were too much.

## AI Statement
Absolutely no AI has been used for these challenges. I'm here to have fun :)
